# Tutorials

Step-by-step tutorials covering every major feature of PyGeoVision.

## Learning Path

1. **Data Acquisition** — search and download from 22+ providers
2. **Preprocessing** — atmospheric correction, cloud masking, band stacking
3. **Spectral Indices** — NDVI, NDWI, NDBI, EVI
4. **AI Models** — Prithvi, ChangeFormer, DINOv3
5. **SAR Processing** — Sentinel-1 preprocessing with bug-fix pipeline
6. **GeoAgent** — natural language → complete pipeline
7. **InSAR** — interferogram, coherence, displacement, rate
8. **Visualization** — interactive maps, viewers, time-series

## Project Notebooks

See `projects/` for 25 production-grade project notebooks and `projects/sar/` for

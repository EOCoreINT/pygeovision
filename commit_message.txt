fix: close ~20 real correctness gaps found via systematic audit against pygeofetch

A recurring pattern across this pass: functions whose parameters implied
real behavior (strategy switches, correction toggles, format options)
that had zero actual effect - accepted, documented, and silently
ignored or overridden. Confirmed each with a concrete before/after
measurement, not just passing tests:

  - EOPipeline.select(strategy=...) was a naive positional slice
  - search()'s processing_level/on_provider_failure/timeout were
    overridden with hardcoded values; geometry_file did nothing
  - regularise_buildings() replaced non-rectangular buildings with their
    bounding box (33% area inflation on a simple L-shape)
  - fill_holes(method=bilinear) was identical to nearest
  - TiledInference.infer(nodata_value=...) let nodata pixels skew
    percentile normalisation (2nd percentile computed as literally
    -9999 with 30% nodata coverage) and leak into output predictions
  - InSAR run()'s apply_linear_aps defaulted to True but was never
    applied; the real correction now recovers a known injected
    elevation trend to within 0.12mm of truth (from 15mm)
  - select_insar_pair()'s baseline check was undocumented as
    inapplicable at that stage - now honest, with a real check added
    where genuine baseline data exists (run_native())
  - a severed import chain (models.foundation -> a nonexistent
    advanced.foundation path) was cascading into ~90 test failures

Also: bridges indices.py/postprocess.py to pygeofetch's real
implementations where interfaces genuinely match (keeping native code
where pygeofetch's equivalent uses a different algorithm or drops data);
adds a SNAP-free InSAR path (run_native()) and Groq LLM backend; adds
real TESSERA/AlphaEarth embedding wrappers; removes stale tests for a
previously-removed subsystem.

Full suite: 837 passed, 0 failed, 3 skipped. Every fix here was verified
via revert-check - confirmed the corresponding test fails with the
original bug's exact symptom before trusting it as a real regression
test.
